=====================================================
FLIKATA SOCIAL APP - FULL BACKEND & ADMIN PANEL
cPanel & VPS Installation Guide (Step-by-Step)
=====================================================

এই জিপ ফাইলটিতে সম্পূর্ণ নতুন আপডেট সহ Flikata সোশ্যাল অ্যাপের ফুল ব্যাকএন্ড (PHP API) এবং ওয়েব এডমিন প্যানেল সাজানো রয়েছে।

-----------------------------------------------------
📁 জিপ ফাইলের ভেতরের ডিরেক্টরি ও ফাইলসমূহ:
-----------------------------------------------------
1. /admin/
   - সম্পূর্ণ লাইট মোড এডমিন কন্ট্রোল প্যানেল
   - ডিপোজিট মেথড ও ডিপোজিট রিকোয়েস্ট ম্যানেজমেন্ট
   - নতুন: উইথড্র মেথড (Withdraw Methods - আনলিমিটেড মেথড যুক্ত/এডিট/ডিলিট/লোগো আপলোড)
   - নতুন: উইথড্র রিকোয়েস্ট (Withdraw Requests - কারণ উল্লেখ করে রিজেক্ট ও অটো-রিফান্ড)
   - ইউজার ম্যানেজমেন্ট ও ব্যান সিস্টেম
   - পোস্ট, কমেন্ট, স্টোরিজ, রিলস ম্যানেজমেন্ট
   - ভেরিফিকেশন ব্যাচ ও রিকোয়েস্ট অনুমোদন/বাতিল
   - পুশ ও পেজ নোটিফিকেশন সিস্টেম
   - পাসওয়ার্ড ও এডমিন প্রোফাইল সেটিংস

2. /backend/
   - মোবাইল অ্যাপের জন্য সকল RESTful API এন্ডপয়েন্ট:
     * /backend/auth/          -> লগইন, রেজিস্টার, ওটিপি, পাসওয়ার্ড রিসেট
     * /backend/wallet/        -> ব্যালেন্স, ডিপোজিট, উইথড্র, লেনদেন হিস্ট্রি
     * /backend/posts/         -> টাইমলাইন পোস্ট তৈরি, লাইক, শেয়ার
     * /backend/comments/      -> পোস্ট কমেন্ট ও রিপ্লাই
     * /backend/chats/         -> রিয়েলটাইম মেসেজিং
     * /backend/calls/         -> অডিও কলিং টেলিমেট্রি
     * /backend/stories/       -> ২৪ ঘণ্টার স্টোরিজ
     * /backend/reels/         -> শর্ট ভিডিও রিলস
     * /backend/verification/  -> ব্লু ব্যাচ ভেরিফিকেশন API
     * /backend/config/db.php  -> ডাটাবেজ কানেকশন কনফিগারেশন

3. database.sql
   - মোট ২৬টি টেবিল সহ সম্পূর্ণ ডাটাবেজ স্কিমা।
   - ডিফল্ট পেমেন্ট মেথড (bKash, Nagad, Rocket, Bank)।
   - ডিফল্ট এডমিন একাউন্ট।

4. index.php
   - সার্ভার রুট থেকে স্বয়ংক্রিয়ভাবে এডমিন প্যানেলে রিডাইরেক্ট করে।


-----------------------------------------------------
🚀 cPanel সেটআপ নির্দেশিকা (Step-by-Step Guide):
-----------------------------------------------------

ধাপ ১: ফাইল আপলোড ও এক্সট্রাক্ট
1. আপনার হোস্টিং cPanel এ লগইন করুন এবং "File Manager" ওপেন করুন।
2. "public_html" (অথবা আপনার সাবডোমেন ফোল্ডারে) প্রবেশ করুন।
3. এই "flikata_backend_and_admin_cpanel.zip" ফাইলটি আপলোড করুন।
4. ফাইলটির উপর রাইট-ক্লিক করে "Extract" বাটনে চাপ দিন।

ধাপ ২: ডাটাবেজ তৈরি ও SQL ইমপোর্ট
1. cPanel হোম থেকে "MySQL Database Wizard" এ যান।
2. একটি নতুন ডাটাবেজ ও ব্যবহারকারী তৈরি করুন (সব প্রিভিলেজ / All Privileges টিক দিন)।
3. পাসওয়ার্ডটি সংরক্ষণ করুন।
4. cPanel থেকে "phpMyAdmin" ওপেন করুন।
5. আপনার তৈরিকৃত ডাটাবেজটি সিলেক্ট করে উপরের "Import" ট্যাবে ক্লিক করুন।
6. "Choose File" এ ক্লিক করে 'database.sql' ফাইলটি সিলেক্ট করুন এবং নিচে "Go" বা "Import" বাটনে ক্লিক করুন।
   (এতে ইউজার, পোস্ট, চ্যাট, কল, ডিপোজিট ও উইথড্র সহ সকল ২৬টি টেবিল তৈরি হয়ে যাবে)।

ধাপ ৩: ডাটাবেজ কানেকশন কনফিগারেশন
1. cPanel File Manager থেকে "backend/config/db.php" ফাইলটি এডিট করুন।
2. আপনার তৈরি করা ডাটাবেজের তথ্য বসিয়ে দিন:
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'আপনার_ডাটাবেজ_নাম');
   define('DB_USER', 'আপনার_ডাটাবেজ_ইউজার');
   define('DB_PASS', 'আপনার_ডাটাবেজ_পাসওয়ার্ড');
3. ফাইলটি Save করুন।

ধাপ ৪: এডমিন প্যানেলে লগইন
1. ব্রাউজারে প্রবেশ করুন: https://yourdomain.com/admin/
2. ডিফল্ট এডমিন লগইন তথ্য:
   - Email: admin@gmail.com
   - Password: 11223344
3. লগইন করার পর সেটিংস পেজ থেকে আপনার নিজের ইমেইল ও পাসওয়ার্ড পরিবর্তন করে নিন।

ধাপ ৫: মোবাইল অ্যাপ সংযোগ (Android App ApiClient)
- আপনার Android অ্যাপ্লিকেশনের ApiClient.kt ফাইলে আপনার ডোমেনের ব্যাকএন্ড লিঙ্ক সেট করুন:
  https://yourdomain.com/backend/
